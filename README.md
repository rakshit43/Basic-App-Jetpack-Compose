# Basic App — Jetpack Compose 🚀

An Android application built with **Kotlin** and **Jetpack Compose**, exploring modern Android UI development, navigation, and app functionality.

## 📱 About the Project

Basic App is a learning project focused on building Android interfaces using Jetpack Compose while implementing common application features and screen navigation.

## ✨ Features

- **Login Screen** — User login interface.
- **Splash Screen** — Initial application screen.
- **Profile Screen** — Displays user profile information.
- **Profile Details** — Dedicated profile details screen.
- **Timer Functionality** — Timer-related UI and logic.
- **Navigation** — Navigate between screens using Jetpack Compose.
- **Logout** — Logout confirmation dialog and return to the login screen.

## 🛠️ Tech Stack

- **Language:** Kotlin
- **UI Toolkit:** Jetpack Compose
- **IDE:** Android Studio
- **Build System:** Gradle with Kotlin DSL
- **Platform:** Android

## 🚀 Getting Started

### Prerequisites

- Android Studio
- Android SDK
- JDK compatible with the project's Gradle configuration
- Basic knowledge of Kotlin and Android development

### Installation

1. Clone the repository:

   ```bash
   git clone https://github.com/rakshit43/Basic-App-Jetpack-Compose.git
   ```

2. Open the project in Android Studio.

3. Allow Gradle to sync and download the required dependencies.

4. Select an Android emulator or connect a physical Android device.

5. Click **Run ▶** to build and launch the application.
